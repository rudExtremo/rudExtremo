## About me

I am a QA engineer and independent software developer with commercial experience in web, mobile, API and game testing, backed by more than nine years of engineering experience outside IT.

My core focus is software quality, risk-based testing, API validation and test automation. As an indie developer, I take products from requirements and domain logic through implementation, testing, release and maintenance.

- **Quality assurance:** functional, regression, integration, exploratory and API testing.
- **Test engineering:** automated checks, CI/CD quality gates, test design and diagnostics.
- **Product development:** local-first applications, data integrity, privacy and maintainability.
- **Integrations:** payments, subscriptions, refunds and third-party APIs.

## Engineering principles

- **Quality is a product feature.** Reliability belongs in the design, not just the release checklist.
- **Test the risk, not the checklist.** Prioritize critical behavior, edge cases and failure modes.
- **Automate repeatable verification.** Use CI/CD to make regressions visible early.
- **Protect user data by design.** Treat privacy, data integrity and recovery as core requirements.
